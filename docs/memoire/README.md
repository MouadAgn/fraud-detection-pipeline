# Notes mémoire

Ce dossier contient, pour chaque étape du projet, une note rédigée en français
qui explique **les choix faits et pourquoi**. Ces notes sont la matière première
des Parties 2 et 3 du mémoire MIA26 : elles sont écrites au fil de la
construction, pas reconstituées après coup.

Principe : **aucune affirmation sans chiffre vérifiable**. Toute valeur citée
dans ces notes est produite par un script ou un notebook du dépôt, et donc
rejouable.
